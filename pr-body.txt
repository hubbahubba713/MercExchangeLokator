This PR removes the native SnaptureCLI build dependency from the active solution and preserves the original native source in SnaptureCLI.archived/ for future reference.

It also adds a managed fallback implementation via MercExchangeLokator/SnaptureShim.cs, updates MercExchangeLokator/MercExchangeLokator.csproj to include the shim, and updates documentation so the project can build without requiring the ATL/Visual C++ native toolchain.

Changes included:
- Archive SnaptureCLI source tree under SnaptureCLI.archived/
- Add managed capture shim in MercExchangeLokator/SnaptureShim.cs
- Update MercExchangeLokator.sln and MercExchangeLokator.csproj
- Update README.md to document the archive and fallback
- Preserve any helper scripts or support files needed by the archived native source
